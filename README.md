# wheather-py
# 🌦️ Weather App

A simple and responsive **Weather App** built using **Python**. This application provides real-time weather information for any city using a weather API.

## 📌 Features

* 🌍 Search weather by city name.
* 🌡️ Displays current temperature.
* ☁️ Shows weather condition (Cloudy, Sunny, Rainy, etc.).
* 💧 Displays humidity level.
* 🌬️ Shows wind speed.
* 📱 Responsive design for mobile and desktop.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Add your OpenWeather API key in the Python file.
4. Open `index.python` in your browser.

## 📂 Project Structure

weather-app-python/
│── main.py # Main Python file to run the app
│── weather.py # Functions to fetch weather data from API
│── config.py # Store API key and configuration
│── requirements.txt # Python dependencies
│── README.md # Project documentation
